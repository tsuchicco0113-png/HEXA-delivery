# HEXA delivery — コンサート納品リスト

イベント物販の納品内容を入力して、受け取る人にそのまま見せられる「納品書」画面を作る単一HTMLアプリです。

## できること

- 出品者・イベント名・納品日・受取担当の入力
- 商品ごとの 商品名 / 種類 / 納品数 / 単価 の入力(小計・合計は自動計算)
- 「渡す画面」で納品書形式に表示(種類別点数、署名欄つき)
- CSV保存(Excel対応、文字化けなし)
- JSON保存と読み込み(別端末への移行・復元用)
- LINEなどに貼れるテキストのコピー
- 入力内容はブラウザに自動保存(端末ごと)

## 使い方

`index.html` をブラウザで開くだけで使えます。サーバーやビルドは不要です。

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で
Branch を `main` / `/(root)` に設定してください。

## 構成

```
index.html   アプリ本体(HTML/CSS/JS すべて1ファイル)
README.md
```

フォントは Google Fonts(Shippori Mincho / Zen Kaku Gothic New)を読み込みます。
オフラインでも、端末の標準フォントに切り替わって動作します。
